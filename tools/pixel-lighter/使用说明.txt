像素打光器 · Rust 高性能版 v1.0
=====================================

这是什么
--------
把平面像素画变成立体、可打光的工具。
它会根据底图自动生成「法线贴图」和「光照遮罩」，然后你在画面上移动光源就能实时看到明暗变化。
算法与 Pixel-Art-Lighter v3.5.23 完全一致（逐字节对照验证过），只是换成了 Rust 实现，快很多。

怎么打开
--------
双击 打光工具箱.bat
或者直接双击 tools\pixel-lighter\pixel-lighter.exe
把 PNG 图片拖到 exe 图标上，会直接打开并载入。

三步上手
--------
1) 左上角「打开底图」，或者把 PNG 拖进窗口。
2) 左侧「③ 生成立体法线」点一下「生成立体法线」（默认参数就够用）。
3) 在中间画布上移动鼠标 —— 光源跟着走，明暗实时变化。

调出满意的效果后，点顶部「导出最终图」存 PNG；想连法线图一起存就点「导出全部」。

拖入图片的规则
------------
· 直接把 PNG 拖进窗口   → 替换底图（画布上已有图也会换掉）
· 文件名带 法线/normal   → 替换法线图
· 文件名带 遮罩/mask/光照 → 替换光照遮罩
· 拖到左侧某个素材卡上    → 只替换那一张（卡片会高亮提示）
· 拖动悬停时窗口中央会显示松手后会发生什么

快捷键
------
Ctrl+O        打开底图
Ctrl+S        导出最终图
Ctrl+Shift+S  导出全部（三张一起）
Ctrl+Z        撤销（生成 / 导入 / 手动修正 / 清除）
Ctrl+Y        重做
Tab           收起 / 展开左侧参数栏（画布变大）
V             底图 → 法线 → 遮罩 → 最终合成 循环切视图
F             画布缩放到刚好放下
1             原始像素大小（1:1）
[ / ]         调小 / 调大手动画笔
Esc           退出画笔选区模式

界面说明
--------
顶部      打开底图 / 导出最终图 / 导出全部 / 重置打光 / 撤销 / 重做 / 收起侧栏
左侧 ①    素材：底图、法线图、光照遮罩三张图，每张都能 导入 / 导出 / 自动生成
左侧 ②    打光参数：亮度、光圈半径、光源高度、环境光、遮罩影响、光色、背景色
左侧 ③    生成立体法线：预设（建筑/物体/地形/角色）+ 起伏强度、法线强度、柔化遍数、分面数量
左侧 ④    生成光照遮罩：强度、最暗处、最亮处、凹槽压暗
左侧 ⑤    手动修正：画笔刷选区，给指定区域强行指定朝向或遮罩亮度
底部      四个模式的缩略图预览，点一下就切换：最终合成 / 底图 / 法线 / 遮罩
          法线 / 遮罩还没有内容时，直接点缩略图就会生成
          右边是缩放按钮：－ ＋ 1:1 适应

操作
----
滚轮        缩放（以鼠标位置为中心）
中键拖动    平移
空格        缩放回刚好放下整张图
左键拖动    移动光源
勾掉「光源跟随鼠标」后，只有按住左键才移动光源，方便腾出手看细节
画布左下角会显示鼠标所在像素坐标（放大到 6 倍以上还会高亮当前像素格）

参数怎么调（大白话）
------------------
亮度        光源总强度，太大亮部会变白
光圈半径    光能照多远，越大过渡越柔和，越小越像聚光灯
光源高度    光源离画面多高，越大越接近均匀的平行光
环境光      照不到的地方保留多少底图亮度，0 就是背光面全黑
遮罩影响    遮罩对受光的影响程度，0 = 不用遮罩
背景色      配合「隐藏背景色」，把背景当透明只给主体打光，点「检测」可自动识别

命令行批量（可选）
----------------
在命令行里带参数运行就是批处理模式，会输出
  原名-最终合成.png / 原名-法线图.png / 原名-光照遮罩.png

  pixel-lighter.exe --input 图.png
  pixel-lighter.exe --input-dir 某目录 --out 输出目录
  pixel-lighter.exe --help          查看全部参数

同目录自动带图
------------
打开底图时，如果同目录有「原名-法线图.png」「原名-光照遮罩.png」，会自动一起载入，
所以用命令行批量生成过之后，再回界面里微调会很方便。

备注
----
· 只支持 PNG。
· 需要中文字体，会从 C:\Windows\Fonts 里找微软雅黑/黑体/等线。
· 单文件 exe，不需要装运行库。
