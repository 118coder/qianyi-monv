## 7. 硬约束（改之前先看，违反会静默坏）

1. **`ArpgData.GRID` 固定 32，不要为图块尺寸改它**。缩一半 = A\* 节点 ×4，直接冲击万敌压测。需要更大空间就用 footprint。
2. **`TILE` 是 `GRID` 的别名，不要删**——53 处旧引用靠它活着。
3. **`.tscn` 的裸标识符是 ASCII-only**（`VariantParser` 用 `is_ascii_alphabet_char`）。`@export` 变量名必须是 ASCII，中文标签靠翻译域补。中文只能出现在**带引号的字符串**里（如节点名 `"世界"`）。
4. **按节拍调用的函数不能用 `delta` 计时**。`ai.think()` 每 0.15s 跑一次，传进来的是单帧时长，累加会慢约 9 倍。要计时用墙钟。
5. **跨脚本引用未进 class cache 的新类，一律 `const X := preload(...)`**。
6. **pixelfx 渲染必须加 `--no-actor`**，否则演示小人会被画进每一帧。
7. **`vendor/pixelfx/.gdignore` 不能删**。
8. **经济口径**：单只怪总价值仍是 `gold_drop_min ~ gold_drop_max`，掉落的只是"表现形式"。改 `drops` 段不要顺带改总价值，会通胀。
9. **`balance.json` 的 `drops` / `camera` / `minimap` 段保存即热重载**，别在代码里写死这些参数。
10. **改任何系统后跑三层测试是硬性流程**——这条是整套工程唯一有效的防线。
