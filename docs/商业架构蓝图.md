## 二、目标架构

```
res://
├── core/                    # 与玩法无关的基座
│   ├── flow/                # 游戏流程状态机（G2）
│   ├── audio/               # 总线/BGM/音效池（G3）
│   ├── settings/            # 设置持久化+应用（G4）
│   ├── save/                # 槽位存档（G5）
│   ├── l10n/                # 字符串表（G6）
│   └── validate/            # 内容校验（G7）
├── game/
│   ├── meta/                # 经营主循环：天/租金/还债/商人等级（G1）
│   ├── run/                 # 一次地牢探险（现 main 的地牢部分）
│   ├── combat/              # 伤害管线/状态效果（G9）
│   └── party/               # 现有队伍系统迁入
├── ui/
│   ├── theme/               # Godot Theme 资源（token 落地为 Theme）
│   └── screens/             # 每屏一脚本（title/shop/hud/menu/…）
├── data/                    # balance.json + maps/ + 内容包
└── assets/
```

**流程脊柱（G1）——商业循环的状态机**：
```
标题 → 准备日（白天：店铺营业/进货/银行还贷）→ 出击（地牢 Run）
  ↑                                              ↓
  ←── 结算（战利品入库/售出）←── 撤退/死亡/凯旋 ←──┘
每一天 = 一个循环；租金期限（如第 10 天还 3000G）是玩家的核心压力源
```

## 四、分期路线图

- **R1 地基期（现在）**：R1/R3/R4/R5/R6/R7/R8 —— 全部是"现在不做以后每一步都更贵"的结构件
- **R2 玩法期**：R2 经营主循环 + R9 伤害管线 + 地牢内容量（10 层/词缀/Boss 变体）
- **R3 内容期**：任务链、叙事、商店等级、成就、本地化执行
- **R4 发布期**：Steam 配置、成就接入、Demo 切片、压测、无障碍选项
